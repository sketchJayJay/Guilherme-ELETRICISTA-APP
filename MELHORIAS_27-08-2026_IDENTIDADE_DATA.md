# Atualização 27/08/2026 — Data, identidade e simplificação

## Corrigido: data ao aprovar orçamento
- A data escolhida no campo **Dia do serviço** agora é a fonte principal ao transformar orçamento em serviço.
- O sistema não usa mais a data de hoje silenciosamente caso a data não seja recebida.
- Se não houver uma data válida, o serviço não é criado e o sistema pede para escolher a data novamente.
- Foi incluída confirmação visual da data escolhida antes da aprovação.
- O aviso de sucesso confirma a data em que o serviço foi criado.

## Nova identidade
- Nome padrão atualizado para **Guilherme Elétrica e Climatização**.
- Instalações existentes com o nome antigo **Guilherme Elétrica** são atualizadas automaticamente.
- Logo oficial aplicada no menu lateral, login, primeiro acesso, impressão e PDF de orçamento.
- Ícones do aplicativo/PWA atualizados com o símbolo da marca.

## Interface mais simples
- A aprovação do orçamento ficou em destaque.
- Status secundários e exclusão foram agrupados em **Outras ações**.
- Botões das tabelas foram ajustados no smartphone para evitar palavras quebradas em várias linhas.
