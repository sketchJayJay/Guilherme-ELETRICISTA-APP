# Ajuste mobile / iPhone

- Corrigida a área superior no iPhone para o cabeçalho não ficar por baixo do relógio, Dynamic Island ou notch.
- Status bar do PWA alterada para modo opaco (`black`) em vez de `black-translucent`.
- Cabeçalho agora respeita `safe-area-inset-top`.
- Botão do menu aumentado para 48x48px para facilitar o toque.
- Logo do topo reduzida no celular para sobrar espaço de clique.
- Sidebar também respeita a área segura superior e inferior.
- Barra inferior respeita o Home Indicator.
- Campos usam 16px no mobile para evitar o zoom automático do Safari.
- Botões e navegação receberam áreas de toque maiores.
